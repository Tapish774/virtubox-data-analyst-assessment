# VirtuBox Data Analyst Assessment

**Candidate:** Tapish Kumar  
**Profile:** Trainee - Data Analyst  

## Project Overview
This repository contains the end-to-end data analytics assessment analyzing 100,000+ e-commerce transactions from the Olist Brazilian E-Commerce dataset. The project identifies logistics delivery bottlenecks, assesses SLA impact on customer review scores, and outlines strategies to improve platform retention.

## Repository Contents
* `analysis.py`: Python script for data cleaning, transformation, and statistical calculations.
* `presentation.md`: Complete 7-slide executive management presentation script.
* `processed_data.csv`: Cleaned and transformed analytical dataset.

## Key Insights Summary
1. **Fulfillment SLA Breach Impact:** On-time orders average a 4.27/5.0 review score, whereas late orders drop to 1.68/5.0 (a 60.6% decrease).
2. **Customer Retention Deficit:** Only 3.12% of unique buyers made a repeat purchase, indicating heavy dependency on top-of-funnel customer acquisition.
3. **Logistics Latency:** Deliveries within São Paulo average 8.3 days, while shipments to Northeast regions average 21 to 28 days, accounting for 74% of all SLA breaches.
